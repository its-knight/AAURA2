Drop your audio files here with these exact names and SoundManager.gd
will pick them up automatically (nothing else to configure):

  music_loop.ogg          - looping background music
  sfx_jump.ogg            - jump
  sfx_coin.ogg            - coin pickup
  sfx_crash.ogg           - hitting a rock / game over
  sfx_level_complete.ogg  - reaching the finish line
  sfx_button.ogg          - menu button press
  sfx_ramp.ogg            - launching off a golden ramp

If a file is missing, the game runs fine silently for that sound -
nothing will error or crash.
